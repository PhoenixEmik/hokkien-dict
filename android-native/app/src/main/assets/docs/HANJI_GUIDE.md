# 漢字用字原則

本頁整理教育部《教育部臺灣台語常用詞辭典》對台語漢字書寫的核心原則，作為 App 內閱讀版本。

來源：
- https://sutian.moe.edu.tw/zh-hant/piantsip/hanji-iongji-guantsik/

## 漢字狀況

臺灣台語與華語在語音、詞彙、句法皆有明顯差異，且分支早、演化路徑不同。
因此在書寫上常有爭議：

- 一部分詞有較穩定的本字可考。
- 另一部分詞來源不明，甚至並非漢語來源，形成「有音無字」問題。

## 本辭典用字類型

本辭典採漢字書寫，原則上朝「一音一漢字」方向處理，依使用現況與辭典體系選字。

### 1. 本字

在傳統文獻中有字形，且意義與台語詞彙具同源關係。

- 例：phang「香」用【芳】
- 例：sè「小」用【細】

### 2. 訓用字

借義不借音：採用語義相同的字形呈現對應詞義，音讀則依台語系統。

- 例：「人」字形台語可讀 jîn；表示「人」之義另有 lâng，本字可作【農】或【儂】。
- 本辭典多以【人】表示，讀作 lâng 時視為訓用字。

### 3. 俗字、借音字與新造字

- **俗字／借音字**：民間或文獻常見，借字音表達音同或音近而詞義不同之詞。
- **新造字**：當音讀與詞義皆無合用漢字時，依形聲或會意造字。
  - 例：【𬦰】peh（形聲）
  - 例：【躼】lò（會意）

## 替代字說明

非本字用字統稱「替代字」，如訓用字、俗字等。
雖原則上傾向本字，但在下列情況會採替代字：

1. 本字過於艱深，普遍讀者不熟悉。
   - 例：tshân 本字【塍】，實作上常用【田】。
2. 與標準語用字同義且屬高頻基本字，本字反而影響閱讀。
   - 例：lâng 本字可作【農】或【儂】，仍常採【人】。
3. 俗字已廣泛約定俗成，改動成本高。
   - 例：thâi「宰殺」本字【治】，常用俗字【刣】。

選字亦考量「望字生音義」：

- 例：làm（低窪泥濘）有【坔】與【湳】兩寫法。
- 若比較表音與表義連結，傾向採形聲功能更明確者（如【湳】）。

## 推薦用字

教育部分別於 96、97 年公告「臺灣台語推薦用字」共 700 字詞。
本辭典原則上遵循其成果，並參考《臺灣台語漢字之選用原則》。
